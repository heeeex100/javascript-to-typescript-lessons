## 边看边练

### 改一份结果，为什么旧数据也跟着变了

任务页面想保留修改前的列表，用来比较或撤销。只换一个变量名不够；要确认是否还在改同一个对象。这个例子只把一项标记为完成。

#### 1 · 先删对，不改旧数组

先猜输出，再点运行。看不懂的行留到下一步逐行解释，不需要边看边查一串术语。

```ts
interface Item { id: number; done: boolean }
const before: Item[] = [{ id: 1, done: false }, { id: 2, done: false }];
const after = before.map(item =>
  item.id === 1 ? { ...item, done: true } : item
);
console.log(before[0].done, after[0].done);
console.log(before === after, before[1] === after[1]);
```

原例可在终端运行：`npm run concept -- 12`。

before 放着两项任务。map 逐项看：id 是 1 时，创建 `{ ...item, done:true }` 这个新对象；不是 1 时，沿用那项对象。

第一组输出 false true：before 的第一项仍没完成，after 的第一项已完成。说明这次修改没有把旧第一项也改掉。

第二组输出 false true：两个数组不是同一个；但没修改的第二项仍是同一个对象。这是有意保留没变的部分，不表示每项都被完整复制。

如果写 after = before，再改 after[0].done，就会同时看到 before 也变了。两个名字可能读到同一个东西，这就是要实际检查的地方。


##### 就地小练习 12-01 · 先删对，不改旧数组

返回去掉目标 id 的新数组。

```ts
function remove(ids: number[], target: number): number[] { ids.splice(ids.indexOf(target),1); return ids; }
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 12-01 --prepare`，编辑 `practice/steps/12-01.ts`，再运行 `npm run drill -- 12-01 --check`。

<details>
<summary>一点提示</summary>

filter 生成新数组；splice 会改旧数组。

</details>

<details>
<summary>试过后再看解释</summary>

```ts
function remove(ids: number[], target: number): number[] { return ids.filter(id => id !== target); }
```

需要同时验证新结果正确和旧数据仍在。

</details>

#### 2 · 找不到时不要误删

删除也一样。先试 `const after = before.filter(item => item.id !== 1)`，得到去掉第一项的新数组；再观察 before 仍是两项。

对比 splice：它直接改原数组。更要注意 findIndex 找不到时是 -1，splice(-1,1) 会删最后一项，正好违背“找不到就失败”。

先完成下面三道题：正确删并保留旧数组、目标不存在、复制要改的对象。最后再组合成综合大练习的成功或失败结果。

如果要保留自己的实验，先运行 `npm run concept -- 12 --prepare`，修改创建的文件，再用 `npm run concept -- 12 --local` 运行。HTML 保存后刷新浏览器。重复准备会保留你已有的文件。


##### 就地小练习 12-02 · 找不到时不要误删

沿用 filter，让目标不存在时所有数据保持。

```ts
function remove(ids: number[], target: number): number[] { const out=[...ids]; out.splice(out.indexOf(target),1); return out; }
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 12-02 --prepare`，编辑 `practice/steps/12-02.ts`，再运行 `npm run drill -- 12-02 --check`。

<details>
<summary>一点提示</summary>

目标不存在时，每一项都应符合 id !== target。

</details>

<details>
<summary>试过后再看解释</summary>

```ts
function remove(ids: number[], target: number): number[] { return ids.filter(id => id !== target); }
```

没有找到是正常分支，不能把 -1 当作有效删除位置。

</details>

#### 3 · 只替换要变的对象

保留旧数据、创建新结果的约定叫**不可变更新**。不修改外部数据、只根据输入算结果的函数更容易单独验证。

readonly 能帮你在编译期发现一些直接写入，但它不会在运行时自动深度冻结对象。先证明 before 没变，再考虑用类型约束辅助。

做完小练习后，回综合大练习把这些动作组合起来。若某一步仍说不清，就回到对应小题换一个数字再试；此时读更长的术语表帮助不大。


##### 就地小练习 12-03 · 只替换要变的对象

把 id=1 的 done 改为 true，返回新对象，保留 before。

```ts
const before={id:1,done:false};
const after=before;
after.done=true;
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 12-03 --prepare`，编辑 `practice/steps/12-03.ts`，再运行 `npm run drill -- 12-03 --check`。

<details>
<summary>一点提示</summary>

对象展开 ...before 可以带上旧字段，再指定新 done。

</details>

<details>
<summary>试过后再看解释</summary>

```ts
const before={id:1,done:false};
const after={...before,done:true};
```

保留旧数据要照顾对象本身，不能只换一个变量名。

</details>

## 综合大练习：支持删除和重命名的任务服务

**组合不可变更新、输入校验和成功/失败结果，保留修改前的任务列表。**

### 完成要求

- removeTask(tasks,id) 删除目标，renameTask(tasks,id,title) 重命名目标；都返回 Result<Task[]>。
- id 不存在时返回失败，不得误删最后一项。
- 新标题去掉两侧空格，空白标题返回失败。
- 成功返回新数组，不修改原数组或旧任务对象。

### 输入与预期结果

删除 id=1 → 只剩 id=2；重命名 id=1 为“ 新标题 ” → 新列表标题为“新标题”，旧列表仍为 A；不存在 id → 失败。
