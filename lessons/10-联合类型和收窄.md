## 边看边练

### 不知道传进来什么时，先问清楚再使用

一个函数可能收到文字，也可能收到 null 或数字。要求“未知输入都能安全处理”，就不能一上来调用 trim。先检查，再使用。

#### 1 · 先检查输入类型

```ts
type ReadResult = { ok: true; value: number } | { ok: false; error: string };
function readCount(input: unknown): ReadResult {
  if (typeof input !== "number" || !Number.isFinite(input)) {
    return { ok: false, error: "需要有限数字" };
  }
  return { ok: true, value: input };
}
const result = readCount("3");
if (result.ok) console.log(result.value);
else console.log(result.error);
```

原例可在终端运行：`npm run concept -- 10`。

`input: unknown` 表示“任何东西都可能进来，目前还不确定”。不知道它是什么时，不能直接调用它的字符串方法。

例子先问 `typeof input !== "number"`：如果不是数字，就返回失败。`!Number.isFinite(input)` 还排除无效数字。只有这些判断都没挡住，后面才返回成功的数字。

返回结果有两种样子：成功有 ok:true 和 value；失败有 ok:false 和 error。不要把它们当成一个永远同时拥有两个字段的对象。

调用处先看 result.ok。成功分支读取 value，失败分支读取 error。例子传入 "3"，这是文字，所以打印“需要有限数字”。

示例检查数字，下面的小练习改为检查字符串：规则写成 typeof input === "string"，只有确认是字符串后才调用 trim。相同的是“先检查，再使用”，不是要求两题接受同一种类型。


`type ReadResult = ...` 为一个类型描述起别名，不是给运行时变量 ReadResult 存值。这里的 `|` 组合两种允许的类型，不是第 02 关的逻辑或 `||`，也不是要求对象同时具有两边的全部字段。

类型里的 `ok: true` 限定这一分支只能用 true；若写 `ok: boolean`，就可能是 true 或 false，会丢失这里用于区分结果的精确信息。类型里的 true、false、`"success"` 这类具体值要求，叫字面量类型。运行时的 `if (result.ok)` 则实际读取数据、选择分支，两层约定要一致。

##### 就地小练习 10-01 · 先检查是不是文字

只有字符串才返回去空格后的文本；其他输入返回空字符串。

```ts
function clean(input: unknown): string { return input.trim(); }
```

本题在本地文件中完成，网页提供起点预览。本地运行 `npm run drill -- 10-01 --prepare`，编辑 `practice/steps/10-01.ts`，再运行 `npm run drill -- 10-01 --check`。

<details>
<summary>一点提示</summary>

unknown 表示还没确定拿到什么。

</details>

<details>
<summary>参考答案与解释</summary>

```ts
function clean(input: unknown): string {
  if (typeof input === "string") return input.trim();
  return "";
}
```

检查之后，编译器才有依据允许字符串方法。

</details>

#### 2 · 再按成功标记读字段

用完整的联合类型观察分支如何决定能读哪个字段：

```ts
type Result = { ok: true; value: string } | { ok: false; error: string };
function display(result: Result): string {
  if (result.ok) return result.value;
  return result.error;
}
console.log(display({ ok: true, value: "已保存" }));
console.log(display({ ok: false, error: "标题为空" }));
```

分别输出“已保存”和“标题为空”。若在 if 前直接读取 result.value，失败分支没有这个字段，类型检查会拒绝。

修改两次调用中的 value 和 error，确认 display 分别取出对应字段；再故意把成功结果写成 { ok: true, error: "错误" }，类型检查应指出成功结果缺少 value。

综合大练习把这个做法换到标题文本：先问是不是字符串，再 trim，再问还剩不剩字。每一步只增加一个判断。


##### 就地小练习 10-02 · 再按成功标记读字段

成功时返回 value，失败时返回 error。

```ts
type Result = {ok:true;value:string}|{ok:false;error:string};
function text(result: Result): string { return result.value; }
```

本题在本地文件中完成，网页提供起点预览。本地运行 `npm run drill -- 10-02 --prepare`，编辑 `practice/steps/10-02.ts`，再运行 `npm run drill -- 10-02 --check`。

<details>
<summary>一点提示</summary>

if (result.ok) 或三元表达式都可以。

</details>

<details>
<summary>参考答案与解释</summary>

```ts
type Result = {ok:true;value:string}|{ok:false;error:string};
function text(result: Result): string { return result.ok ? result.value : result.error; }
```

标签把成功字段和失败字段区分开。

</details>

#### 3 · 最后拒绝空白标题

先排除非字符串，再判断去空格后是否有内容：

```ts
function isTitle(input: unknown): boolean {
  if (typeof input !== "string") return false;
  return input.trim().length > 0;
}
console.log(isTitle(" JS "), isTitle("   "), isTitle(null));
```

输出 true、false、false。类型检查让 trim 可以安全调用，长度检查再排除纯空白。

把“可能是什么”用检查逐渐确定下来，叫**类型收窄**。`A | B` 表示可能是 A，也可能是 B，叫**联合类型**。

ok:true / ok:false 是辨别这次结果属于哪种情况的标记。unknown 类型的值需要经过判断才能使用；any 会跳过许多类型检查。


##### 就地小练习 10-03 · 最后拒绝空白标题

只接受去空格后仍有字的字符串。

```ts
function accepted(input: unknown): boolean { return typeof input === "string"; }
```

本题在本地文件中完成，网页提供起点预览。本地运行 `npm run drill -- 10-03 --prepare`，编辑 `practice/steps/10-03.ts`，再运行 `npm run drill -- 10-03 --check`。

<details>
<summary>一点提示</summary>

&& 右侧只会在左侧成立后执行。

</details>

<details>
<summary>参考答案与解释</summary>

```ts
function accepted(input: unknown): boolean { return typeof input === "string" && input.trim().length > 0; }
```

类型检查与业务检查各解决一层问题。

</details>

## 综合大练习：标题输入与结果展示

**将未知输入校验、成功/失败结构和调用方展示连成完整流程。**

### 完成要求

- parseTitle(input:unknown) 只接受去空格后非空的字符串，成功返回 {ok:true,value}。
- 非法输入返回 {ok:false,error:string}，错误原因非空。
- describe(result) 先按 ok 区分结果：成功返回“已接收：标题”，失败返回“失败：原因”。

" 学习 " → {ok:true,value:"学习"} → "已接收：学习"；null → 失败结构 → "失败：具体原因"。
