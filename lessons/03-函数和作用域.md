## 一步一步看懂，再拆开练

一次只看一小步。先运行具体代码、逐行看值怎样变化，做几个小练习后再组合成主挑战。

### 函数怎样接收数字，又把结果交回来

想象结账：给程序“单价 7 元、买 3 件”，希望它交回 21。函数就是给这段计算起一个名字，后面换一笔订单还能再用。先不用默认参数和箭头写法。

#### 1 · 先看这一个例子

先猜输出，再点运行。看不懂的行留到下一步逐行解释，不需要边看边查一串术语。

```js
function cost(price, count) {
  return price * count;
}
const payment = cost(7, 3);
console.log(payment);
```

原例可在终端运行：`npm run concept -- 03`。

#### 2 · 一行一行看它做了什么

第一到三行只是在说明 cost 怎么工作，还没有买任何东西。`price, count` 是两个接收位置，你可以先读作“单价、数量”。

执行到 `cost(7, 3)` 时，才真正开始算：这次 price 是 7，count 是 3。到函数里算 7×3，得到 21。

`return` 把 21 交回调用的位置，所以这一行等价于 `const payment = 21`。之后 console.log 才把 payment 的值显示出来。

对比 `console.log(price * count)`：它只负责当场显示 21，并没有把这个数交回来。如果函数没有 return，调用方拿到 undefined，表示这里没有返回你想要的值。屏幕看到数字，不等于下一段代码拿到了数字。

#### 3 · 改一点，再看一次

先把调用改为 cost(5, 2)，应得到 10。再改为 cost(5, 0)，应得到 0。不要修改函数体，这样才能体验“同一段方法，换输入复用”。

再把 return 那一行改成 console.log(price * count)。观察会先打印 10，再打印 undefined。恢复 return，并尝试 `const doubled = cost(5, 2) * 2`。

最后才认识简写：`const double = value => value * 2` 可以先读成“接收 value，返回 value×2”。如果写成 `value => { ... }`，花括号内还要写 return 才能交回结果。

如果要保留自己的实验，先运行 `npm run concept -- 03 --prepare`，修改创建的文件，再用 `npm run concept -- 03 --local` 运行。HTML 保存后刷新浏览器。重复准备会保留你已有的文件。

#### 4 · 分开练，先不做整道题

1. **先让调用方拿到结果**：multiply 能打印 12，但调用方拿不到。补上返回值。
2. **参数每次都可以换**：实现 greet(name)，传“小林”返回“你好，小林”，传“阿明”也应该跟着换。
3. **再把两个函数连起来**：写 double，让它把传入的值乘 2；调用中先算 3+4，再把结果交给 double。

#### 5 · 做过之后，再认识这些名字

函数定义里接收数据的名字叫**形参**，调用时传的具体数据叫**实参**。调用表达式拿回来的东西叫**返回值**。

函数内创建的变量通常只能在里面使用，想给外面用，就返回它。`count = 1` 这种默认参数表示没传 count 时使用 1；传 0 则应使用 0，这部分可以等主挑战完成后再试。

做完小练习后，回主挑战把这些动作组合起来。若某一步仍说不清，就回到对应小题换一个数字再试；此时读更长的术语表帮助不大。

### 03-02 · 参数每次都可以换

实现 greet(name)，传“小林”返回“你好，小林”，传“阿明”也应该跟着换。

```js
function greet(name) { return "你好，小林"; }
```

在实验台选择这道小题，或运行 `npm run drill -- 03-02 --prepare` 后编辑 `practice/steps/03-02.js`，再运行 `npm run drill -- 03-02 --check`。

<details>
<summary>一点提示</summary>

在函数内部读 name 就能拿到这一次传进来的名字。

</details>

<details>
<summary>试过后再看解释</summary>

```js
function greet(name) { return `你好，${name}`; }
```

形参 name 可以理解为本次调用接收名字的入口。

</details>

### 03-03 · 再把两个函数连起来

写 double，让它把传入的值乘 2；调用中先算 3+4，再把结果交给 double。

```js
function double(value) { return value; }
const result = double(3 + 4);
```

在实验台选择这道小题，或运行 `npm run drill -- 03-03 --prepare` 后编辑 `practice/steps/03-03.js`，再运行 `npm run drill -- 03-03 --check`。

<details>
<summary>一点提示</summary>

函数接收到的是已经算出的 7。

</details>

<details>
<summary>试过后再看解释</summary>

```js
function double(value) { return value * 2; }
const result = double(3 + 4);
```

一个函数的返回值可以继续参加下一步计算。

</details>
