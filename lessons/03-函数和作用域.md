### 函数、调用、返回值与作用域

**函数**给一段可复用的操作起名字。定义函数只是在说明“怎么做”，调用它才会执行。函数可以接收输入、返回结果，也可能打印日志或修改外部状态。

- **形参与实参**：定义中的 price、count 是形参；调用时传入的 7、3 是实参。每次调用都会建立自己的局部变量。
- **默认参数**：`count = 1` 在没有传值或传 undefined 时生效；传 0 或 null 不会触发默认值。
- **返回值**：`return value` 把值交给调用方并立即结束本次调用。没有 return 时，普通函数返回 undefined；打印只是副作用，不是返回。
- **作用域**：函数内部声明的 subtotal 只能在它的作用域内访问；调用方通过返回值获得结果。
- **箭头函数**：`x => x * 2` 是接收 x 并返回两倍值的简写。改为带花括号的 `x => { ... }` 后，要显式写 return 才有相应返回值。

<details>
<summary>读例子 → 改一个地方 → 检查理解</summary>

```js
function cost(price, count = 1) {
  const subtotal = price * count;
  return subtotal;
}
const payment = cost(7, 3);
const double = value => value * 2;
console.log(payment, double(payment));
```

**逐步理解**：cost(7, 3) 执行后返回 21，payment 保存这个结果；double 再返回 42。定义 cost 时还没有计算任何订单。

**动手试一试**：把 return subtotal 改为 console.log(subtotal)，观察调用方拿到什么；实验后恢复。再比较 cost(7)、cost(7, 0)。

**先回答，再展开**：value => { value * 2; } 为什么不能像 value => value * 2 那样返回两倍值？

<details>
<summary>查看解释</summary>

前者的花括号是函数体，其中的表达式只被计算，没有被 return；后者使用表达式函数体，表达式结果会被隐式返回。
