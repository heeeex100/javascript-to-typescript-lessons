## 边看边练

### 先让电脑显示一句你写的话

这段程序会保存一个名字，再把它显示出来。你可以把“小林”换成自己的名字，看看输出怎么变。

#### 1 · 把名字保存下来

```js
const learner = "小林";
console.log(learner);
```

原例可在终端运行：`npm run concept -- 00`。

第一行用 const 声明变量 learner。等号右侧的 `"小林"` 是你要存的内容。引号告诉电脑：这是原样文字，不是命令。

第二行的 `console.log(...)` 会把括号里拿到的内容显示到输出区。这里写的是 learner，没有引号，因此会先找出 learner 里存的值，显示“小林”。

现在对比 `console.log("learner")`：这次引号要求原样显示，所以输出是 learner 这几个英文字母。电脑不会猜测你其实想要人名。

先试一次：把第一行的“小林”换成自己的名字，再运行，输出应跟着变。

写代码时，保留例子里的英文引号和分号。`learner` 是你给数据取的名字，后面使用时要拼写一致。

##### 就地小练习 00-01 · 把名字保存下来

只改引号中的文字，让 learner 的值是“小林”。

#### 2 · 引号会改变这行代码的意思

```js
const minutes = "10 + 5";
console.log(minutes);
```

这里输出的是文字 10 + 5，并没有做加法。引号里面的内容会原样保存。把引号去掉，改成 `const minutes = 10 + 5`，输出就变成数字 15。

“小林”是文字，要加引号；想让程序计算 10 + 5，就把算式写在引号外。

##### 就地小练习 00-02 · 算式先算完，再保存

让 minutes 保存 10 + 5 的计算结果，得到数字 15。

```js
const minutes = "10 + 5";
console.log(minutes);
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 00-02 --prepare`，编辑 `practice/steps/00-02.js`，再运行 `npm run drill -- 00-02 --check`。

<details>
<summary>一点提示</summary>

想让计算机算数时，10 + 5 外面需要引号吗？

</details>

<details>
<summary>参考答案与解释</summary>

```js

console.log(minutes);
```

带引号时存下的是六个字符；去掉引号后才执行加法。

</details>

#### 3 · 把名字放进一句话

```js
const learner = "小林";
const message = `${learner}今天学 JS`;
console.log(message);
```

输出是“小林今天学 JS”。message 两边用反引号包住整句话，`${learner}` 这个位置会换成 learner 中的内容。把名字改成“阿明”，同一行代码就会输出“阿明今天学 JS”。

如果写成普通引号 `"learner今天学 JS"`，里面的 learner 就只是几个字母，不会被换成人名。

learner 是**变量名**，“小林”这样的文字值叫**字符串**。带 `${...}` 的这段写法叫**模板字符串**。下一题要用它把名字放进一句完整的话里。

JS 是我们写这些代码的语言。浏览器和 Node.js 都可以执行 JS；在项目终端运行 `npm run concept -- 00`，就能看到本关第一个例子的输出。

##### 就地小练习 00-03 · 把名字放进一句话

改 message 一行，让结果为“小林今天学 JS”，并且 learner 改名后也能跟着变。

```js
const learner = "小林";
const message = "learner今天学 JS";
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 00-03 --prepare`，编辑 `practice/steps/00-03.js`，再运行 `npm run drill -- 00-03 --check`。

## 综合大练习：写一句自己的学习计划

**填写自己的名字、主题和学习分钟数，让程序把它们显示在同一句话里。**

### 题目要求

- 填写名字 learner、学习主题 topic 和分钟数 minutes（大于 0）。
- message 是包含这三项的一句话。改变名字、主题或时长后，输出也要跟着变。

### 输入与预期结果

例如：小林今天学 JavaScript，计划 15 分钟。换名字后，这句话也应跟着变。

### 在哪里写、怎么验收

编辑 [practice/finals/00.js](../practice/finals/00.js)，在项目根目录执行：

```sh
npm run lab -- 00
npm run lab -- 00 --check
```

起点只提供数据或函数外壳，需要自己把本关学过的动作组合起来。已有的旧版 practice 文件仍保留，新的基础综合题使用 practice/finals 目录。网页草稿与本地文件独立。
