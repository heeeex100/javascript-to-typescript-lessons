## 边看边练

### 先让电脑显示一句你写的话

先只学两件事：存下一段文字，把它显示出来。别急着理解运行环境、表达式这些名字。你可以把 learner 理解为这段程序里给名字留的一个位置。

#### 1 · 把名字保存下来

先猜输出，再点运行。看不懂的行留到下一步逐行解释，不需要边看边查一串术语。

```js
const learner = "小林";
console.log(learner);
```

原例可在终端运行：`npm run concept -- 00`。

先看第一行。`const` 表示“创建一个名字”；这里创建的名字是 learner。等号右侧的 `"小林"` 是你要存的内容。引号告诉电脑：这是原样文字，不是命令。

再看第二行。`console.log(...)` 会把括号里拿到的内容显示到输出区。这里写的是 learner，没有引号，因此会先找出 learner 里存的值，显示“小林”。

现在对比 `console.log("learner")`：这次引号要求原样显示，所以输出是 learner 这几个英文字母。电脑不会猜测你其实想要人名。

行尾的分号表示这句话结束了。本课先保留它，不必研究哪些位置能省略。


##### 就地小练习 00-01 · 把名字保存下来

只改引号中的文字，让 learner 的值是“小林”。

```js
const learner = "你的名字";
console.log(learner);
```

#### 2 · 算式先算完，再保存

只把第一行引号里的“小林”改成你的名字，其他地方不动。先说出你预计看到的文字，再运行。

接着把第二行改成 `console.log("learner")`。对比两次输出：哪个读出了存下的名字？哪个只是照着引号显示？最后把引号去掉恢复。

如果要保留自己的实验，先运行 `npm run concept -- 00 --prepare`，修改创建的文件，再用 `npm run concept -- 00 --local` 运行。HTML 保存后刷新浏览器。重复准备会保留你已有的文件。


##### 就地小练习 00-02 · 算式先算完，再保存

让 minutes 保存 10 + 5 的计算结果，得到数字 15。

```js
const minutes = "10 + 5";
console.log(minutes);
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 00-02 --prepare`，编辑 `practice/steps/00-02.js`，再运行 `npm run drill -- 00-02 --check`。

#### 3 · 把名字放进一句话

你刚创建的 learner 叫**变量名**；“小林”这样的文字值叫**字符串**。这两个名称是给刚才的动作起名字，不是需要先背下来的定义。

JS 是你正在写的语言。浏览器能执行它，Node.js 也能执行它。运行 `npm run concept -- 00` 时，Node.js 执行这个例子，你能在终端看到同样的文字。

做完小练习后，回综合大练习把这些动作组合起来。若某一步仍说不清，就回到对应小题换一个数字再试；此时读更长的术语表帮助不大。


##### 就地小练习 00-03 · 把名字放进一句话

改 message 一行，让结果为“小林今天学 JS”，并且 learner 改名后也能跟着变。

```js
const learner = "小林";
const message = "learner今天学 JS";
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 00-03 --prepare`，编辑 `practice/steps/00-03.js`，再运行 `npm run drill -- 00-03 --check`。

<details>
<summary>一点提示</summary>

反引号是 `，不是单引号；${learner} 会读取 learner。

</details>

<details>
<summary>试过后再看解释</summary>

```js
const learner = "小林";
const message = `${learner}今天学 JS`;
```

普通引号中的变量名只是文字；模板中的占位位置会换成变量的值。

</details>

## 本关综合大练习

**把名字、学习主题和计划时长组织成一张会随数据变化的学习卡。**

### 完成要求

- 创建 learner、topic、minutes，名字和主题填写你自己的内容，minutes 为大于 0 的数字。
- message 同时包含这三个值，使用变量组装，改动主题或时长后应跟着变化。
- 打印完整学习卡。

### 输入与预期结果

名字“小林”、主题“JavaScript”、15 分钟 → 输出同时出现这三项。再换成自己的名字和 30 分钟。

### 在哪里写、怎么验收

编辑 [practice/finals/00.js](../practice/finals/00.js)，在项目根目录执行：

```sh
npm run lab -- 00
npm run lab -- 00 --check
```

起点只提供数据或函数外壳，需要自己把本关学过的动作组合起来。已有的旧版 practice 文件仍保留，新的基础综合题使用 practice/finals 目录。网页草稿与本地文件独立。
