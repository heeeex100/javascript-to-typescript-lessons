## 边看边练

### 先让电脑显示一句你写的话

这段程序会保存一个名字，再把它显示出来。你可以把“小林”换成自己的名字，看看输出怎么变。

#### 1 · 把名字保存下来

```js
const learner = "小林";
console.log(learner);
```

原例可在终端运行：`npm run concept -- 00`。

第一行用 const 声明变量 learner。等号右侧的 `"小林"` 是你要存的内容。引号告诉电脑：这是原样文字，不是命令。

第二行的 `console.log(...)` 会把括号里拿到的内容显示到输出区。这里写的是 learner，没有引号，因此会先找出 learner 里存的值，显示“小林”。

现在对比 `console.log("learner")`：这次引号要求原样显示，所以输出是 learner 这几个英文字母。电脑不会猜测你其实想要人名。

**为什么这里有分号？不写行不行？**

`;` 用来明确标记一条语句的结束。这里“保存名字”是一条语句，“显示名字”是另一条。就像两句话用句号分开，程序也需要能分清一条语句到哪里结束。

你可能见过不写分号的 JS，例如：

```js
const learner = "小林"
console.log(learner)
```

这段也会输出“小林”，和上面的版本一样。JS 有一套**自动分号插入**规则，通常简称 ASI。在这里，下一行的 console.log 不能接在前面的字符串后面继续构成同一条语句，解析器能按规则确定边界，因此允许你省略分号。它不是运行时修改你的文件，也不是每遇到换行就自动加一个分号。

换行本身不保证结束语句。比如下面的加法可以跨行写：

```js
const minutes = 10
  + 5;
console.log(minutes);
```

输出是 15。因为 + 5 能接着前面的 10 继续计算，所以这两行属于同一条声明语句。如果你在 10 后面写分号，就明确结束了这条声明，后面的 + 5 不会再加入 minutes。

也有更容易踩坑的情况：下一行以左括号 `(` 或方括号 `[` 开头时，可能被当成上一行表达式的延续，而不是你想写的新语句。后面学函数时，还会遇到 return 后面不能随意换行的情况。

**本课程统一写分号**，让语句边界更明确，也少依赖自动插入规则。不写分号也是 JS 项目中常见的风格，但需要遵守相应的写法；不是单纯把所有分号删掉就总能保持原来的意思。

你可以试两次：

1. 删掉最上面名字例子中的两个分号，保留换行，输出仍是“小林”。
2. 再把它们挤成同一行：`const learner = "小林" console.log(learner)`。这次会报 SyntaxError；在两条语句之间加回分号，就能运行。

语法细节可查阅 [MDN：自动分号插入](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Lexical_grammar#自动分号补全)。


**名字是自己取的，关键字不是**

learner 是这里自己取的变量名，可以统一换成 student；const 是 JS 的关键字，不能把它换成一个随意的词。名字区分大小写，learner 和 Learner 是两个不同的名字。只改声明处、不改使用处，运行时就可能报“找不到这个名字”。

变量名不能以数字开头，也不能包含空格。`learner2` 可以，`2learner` 和 `learner name` 不行；多个单词常写成 learnerName，这只是命名习惯。代码使用半角英文标点，中文输入法的弯引号“ ”不能代替代码中的直引号。

**单引号、双引号和注释**

`"小林"` 和 `'小林'` 都是字符串，选择哪种引号不会改变这里的文字。左右要配对，不能一边单引号、一边双引号。文字里要出现同一种引号，可以换外层引号，例如 `"I'm learning JS"`；也可以写转义字符，例如 `'I\'m learning JS'`。

```js
// 这一整行是注释，不参与执行。
const learner = '小林'; // 双斜线后面是给人看的说明。
console.log(learner);
/* 这也是注释，
   可以跨越几行。 */
```

把 console.log 那一行前面加上 //，再运行就不会显示名字。引号里的 `"//"` 则只是两个斜线字符，不会把后面的代码变成注释。

**console.log 中的点号、括号各做什么？**

console 提供了一组输出等工具，点号从中取出 log，后面的括号才调用它。`console.log(learner)` 是读取 learner 的值并显示；`console.log` 没有调用括号，只是在取这个工具，本身不会显示名字。带引号的 `"console.log(learner)"` 更是一整段文字，不会作为代码执行。

`console.log("名字", learner)` 中的逗号分隔两个传入的值，不是把它们相加。可以把 learner 改成你的名字，再分别运行一个参数和两个参数的版本，比较输出。

#### 2 · 引号会改变这行代码的意思

```js
const minutes = "10 + 5";
console.log(minutes);
```

这里输出的是文字 10 + 5，并没有做加法。引号里面的内容会原样保存。把引号去掉，改成 `const minutes = 10 + 5`，输出就变成数字 15。

“小林”是文字，要加引号；想让程序计算 10 + 5，就把算式写在引号外。

##### 就地小练习 00-02 · 算式先算完，再保存

const minutes = "10 + 5";

#### 3 · 把名字放进一句话

```js
const learner = "小林";
const message = `${learner}今天学 JS`;
console.log(message);
```

输出是“小林今天学 JS”。message 两边用反引号包住整句话，`${learner}` 这个位置会换成 learner 中的内容。把名字改成“阿明”，同一行代码就会输出“阿明今天学 JS”。

如果写成普通引号 `"learner今天学 JS"`，里面的 learner 就只是几个字母，不会被换成人名。

learner 是**变量名**，“小林”这样的文字值叫**字符串**。带 `${...}` 的这段写法叫**模板字符串**。下一题要用它把名字放进一句完整的话里。

JS 是我们写这些代码的语言。浏览器和 Node.js 都可以执行 JS；在项目终端运行 `npm run concept -- 00`，就能看到本关第一个例子的输出。

**反引号还有什么不同？**

单引号或双引号里的 `${learner}` 不会替换成名字，只有模板字符串中的这个位置会计算。模板字符串还允许直接换行；普通引号里要插入换行，通常写 `\n`：

```js
console.log("第一行\n第二行");
console.log(`第一行
第二行`);
```

两个版本都会显示两行。`\n` 在源代码里写成反斜线加 n，字符串中实际表示一个换行字符。
