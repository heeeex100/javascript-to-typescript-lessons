## 边看边练

### 先取出一项数据，再处理一整组

先把对象看作一张带字段的任务卡，把数组看作按顺序放着的几张卡。暂时不用一行里同时写 filter、map 和箭头函数。

#### 1 · 先读一个对象的属性

先猜输出，再点运行。看不懂的行留到下一步逐行解释，不需要边看边查一串术语。

```js
const book = { title: "JS", read: false };
console.log(book.title);
const books = [book, { title: "TS", read: true }];
console.log(books[0].title);
```

原例可在终端运行：`npm run concept -- 04`。

`{ title: "JS", read: false }` 表示一张卡：title 这栏写着 JS，read 这栏写着 false，表示没读过。

`book.title` 先找到 book 这张卡，再取 title 这一栏，所以得到文字 JS。

books 的方括号把两张卡按顺序放成一组。`books[0]` 取第一张；位置从 0 开始，所以第二张是 books[1]。`books[0].title` 先取第一张，再取它的标题，仍是 JS。

下一步才是遍历。你已经在第 02 关学过 for...of：每次取一张卡，看看 read 是否为 false，需要时取它的 title。

#### 2 · 先筛选，不转换

先练 filter：

```js
const books = [{ title: "JS", read: false }, { title: "TS", read: true }];
const unread = books.filter(book => !book.read);
console.log(unread);
```

filter 每次把一张卡交给你写的函数。你交回 true，就留下这张；交回 false，就跳过。`!false` 是 true，所以 !book.read 留下没读过的卡。先观察结果是对象数组，还不是文字数组。

再单独加一行 `const titles = unread.map(book => book.title)`。map 问的是“这一项要换成什么”，这里回答标题，所以得到 ["JS"]。它不是再筛选一次。

最后体验一个坑：`const copy = books` 只是给同一组卡多起一个名字。改 copy[0].read，books[0].read 也会变。`[...books]` 只复制放卡的列表，卡本身仍共享；需要更改卡又保留旧卡时，用 `{ ...book, read: true }` 创建另一张卡。

如果要保留自己的实验，先运行 `npm run concept -- 04 --prepare`，修改创建的文件，再用 `npm run concept -- 04 --local` 运行。HTML 保存后刷新浏览器。重复准备会保留你已有的文件。

#### 3 · 再把对象换成标题

一张带属性的数据叫**对象**，有顺序的一组数据叫**数组**。交给 filter/map、让它们逐项调用的函数叫**回调函数**。

“两个名字指向同一张卡”的关系叫共享**引用**。不用先背“浅拷贝”：先实际改一次对象，看哪个旧值也跟着变，再决定是否需要复制对象。

做完小练习后，回综合大练习把这些动作组合起来。若某一步仍说不清，就回到对应小题换一个数字再试；此时读更长的术语表帮助不大。


##### 就地小练习 04-03 · 再把对象换成标题

传入的都是任务对象，返回标题字符串数组。

```js
function titles(tasks) { return tasks; }
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 04-03 --prepare`，编辑 `practice/steps/04-03.js`，再运行 `npm run drill -- 04-03 --check`。

<details>
<summary>一点提示</summary>

map 需要一段说明“这一项变成什么”的函数。

</details>

<details>
<summary>试过后再看解释</summary>

```js

```

map 不负责选人，只负责把每项转换成你返回的值。

</details>

## 综合大练习：生成任务列表摘要

**把数组筛选、标题转换和数量统计组合成一个可复用的数据处理函数。**

### 完成要求

- 实现 taskSummary(tasks)，返回 {pendingTitles, doneCount, totalCount}。
- pendingTitles 只含未完成任务的标题，顺序与原列表一致。
- doneCount 是完成数量，totalCount 是总数量；空数组返回空标题和两个 0。
- 不得修改传入数组或任务对象。

### 输入与预期结果

A 未完成、B 完成、C 未完成 → pendingTitles=["A","C"]、doneCount=1、totalCount=3。
