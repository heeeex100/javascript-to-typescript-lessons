# 09 · 处理没有备注的任务卡

今天做出来的效果：**有备注时显示备注，缺失或全空格时显示“无备注”。**

<!-- foundations:start -->
## 一步一步看懂，再拆开练

一次只看一小步。先运行具体代码、逐行看值怎样变化，做几个小练习后再组合成主挑战。

### 一张任务卡真的可能没填备注

先想两个输入：一张卡写了备注“重点”，另一张完全没填。函数都要返回能显示的文字。先处理“没填”，再处理“只填空格”。

#### 1 · 先看这一个例子

先猜输出，再点运行。看不懂的行留到下一步逐行解释，不需要边看边查一串术语。

```ts
interface Card { title: string; note?: string }
const card: Card = { title: "复习", note: "   " };
const trimmed = card.note?.trim();
console.log(JSON.stringify(trimmed));
console.log(trimmed ?? "缺失");
console.log(trimmed || "空白或缺失");
```

原例可在终端运行：`npm run concept -- 09`。

#### 2 · 一行一行看它做了什么

`interface Card` 说明这种卡有哪些字段。title: string 要求标题是文字；note?: string 中的问号说“备注可以不提供”。

例子里 note 是三个空格。trim() 去掉两侧空格后，得到空字符串，也就是没有字符的 ""。第一条日志用 JSON.stringify 把引号显示出来，帮助你分清空字符串和没输出。

`card.note?.trim()` 中的 ?. 表示：没提供 note 时就停在这里，结果为 undefined；提供了才调用 trim。

然后比较两个默认值：trimmed ?? "缺失" 在空字符串时仍保留空字符串，所以会看到空行；trimmed || "空白或缺失" 则会替换空字符串，因此显示默认文字。

#### 3 · 改一点，再看一次

先删除对象中的 note 字段，再运行。这时两个默认值都会用上。

再填 note: "  重点  "。去空格后有字，两个运算符都保留“重点”。

最后只填空格，回到本关要求：“没有备注或只有空白，都显示无备注”。所以先用 ?.trim()，再用 ||。如果某个设置合法值允许 0，通常不能用 || 把这个 0 也替掉。

如果要保留自己的实验，先运行 `npm run concept -- 09 --prepare`，修改创建的文件，再用 `npm run concept -- 09 --local` 运行。HTML 保存后刷新浏览器。重复准备会保留你已有的文件。

#### 4 · 分开练，先不做整道题

1. **有时候确实没有备注**：没有 note 时返回“无备注”；这一步不处理空格。
2. **有值时再去空格**：返回去掉两侧空格的备注；缺失时返回 undefined。
3. **空字符串也需要默认值**：已经 trim 完毕。让空字符串也返回“无备注”，有效文字保留。

网页下方有对应的小练习。每次只做一题：先运行起点 → 修改 → 检查 → 说清变化。做对以后换下一题，不需要先把整个主挑战写完。TS 小练习显示本地文件和命令，由真实编译器检查。

#### 5 · 做过之后，再认识这些名字

? 标注的是**可选属性**；?. 是**可选链**，让缺失时停止访问。

?? 只给 null/undefined 补默认值；|| 还会给空字符串、0、false 等补默认值。先写清自己想保留哪些值，再选运算符。

做完小练习后，回主挑战把这些动作组合起来。若某一步仍说不清，就回到对应小题换一个数字再试；此时读更长的术语表帮助不大。
## 本关小步练习

### 09-01 · 有时候确实没有备注

没有 note 时返回“无备注”；这一步不处理空格。

```ts
interface Card { note?: string }
function note(card: Card): string { return card.note; }
```

在实验台选择这道小题，或运行 `npm run drill -- 09-01 --prepare` 后编辑 `practice/steps/09-01.ts`，再运行 `npm run drill -- 09-01 --check`。

<details>
<summary>一点提示</summary>

?? 在左边为 undefined 或 null 时选择右边。

</details>

<details>
<summary>试过后再看解释</summary>

```ts
interface Card { note?: string }
function note(card: Card): string { return card.note ?? "无备注"; }
```

可选意味着可能没提供；读取后要照顾这种情况。

</details>

### 09-02 · 有值时再去空格

返回去掉两侧空格的备注；缺失时返回 undefined。

```ts
function trimNote(note?: string): string | undefined { return note.trim(); }
```

在实验台选择这道小题，或运行 `npm run drill -- 09-02 --prepare` 后编辑 `practice/steps/09-02.ts`，再运行 `npm run drill -- 09-02 --check`。

<details>
<summary>一点提示</summary>

可选链 ?. 在缺失时停下来。

</details>

<details>
<summary>试过后再看解释</summary>

```ts
function trimNote(note?: string): string | undefined { return note?.trim(); }
```

undefined 没有 trim 方法；?. 使缺失分支有明确结果。

</details>

### 09-03 · 空字符串也需要默认值

已经 trim 完毕。让空字符串也返回“无备注”，有效文字保留。

```ts
function show(text: string | undefined): string { return text ?? "无备注"; }
```

在实验台选择这道小题，或运行 `npm run drill -- 09-03 --prepare` 后编辑 `practice/steps/09-03.ts`，再运行 `npm run drill -- 09-03 --check`。

<details>
<summary>一点提示</summary>

|| 会在空字符串时采用右边默认值。

</details>

<details>
<summary>试过后再看解释</summary>

```ts
function show(text: string | undefined): string { return text || "无备注"; }
```

运算符要按需求选：本题特意把空文本和缺失都当作无备注。

</details>
