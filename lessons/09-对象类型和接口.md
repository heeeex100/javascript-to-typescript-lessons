## 动手前先认识

### 对象类型、可选属性与空值

**interface**描述对象应具有哪些属性及其类型。函数接收 Task，意味着传来的值要满足这种结构，不要求它由某个特定类构造。

- **可选属性**：`note?: string` 表示可以没有 note；读取结果可能为 string 或 undefined。必需属性 title 则必须提供。
- **可选链**：`note?.trim()` 在 note 为 null/undefined 时短路为 undefined，否则调用 trim。它不会把错误类型的值自动修好。
- **默认值运算**：`a ?? b` 只在 a 为 null/undefined 时用 b；`a || b` 在 a 为任意假值时用 b，包括空字符串、0、false。本课要求空白备注也回退，所以要先 trim 再判断。
- **readonly**是编译期的写入限制，不等于运行时 Object.freeze，也不自动深度冻结嵌套对象。
- **结构类型**关注“具有哪些成员”，所以已有对象通常可在满足必需成员时传入；直接书写的对象字面量还会受到额外属性检查。

<details>
<summary>读例子 → 改一个地方 → 检查理解</summary>

```ts
interface Card { title: string; note?: string }
const card: Card = { title: "复习", note: "   " };
const trimmed = card.note?.trim();
console.log(JSON.stringify(trimmed));
console.log(trimmed ?? "缺失");
console.log(trimmed || "空白或缺失");
```

**逐步理解**：trimmed 是空字符串：第一行输出两个引号，第二行输出空行，第三行输出“空白或缺失”。?? 保留空字符串，|| 使用默认值。

## 刚才发生了什么

? 表示 note 可以不提供；?. 允许它缺失时停止访问。|| 会给空字符串也提供默认值，本题正好需要这个行为；如果要保留空字符串，则应考虑 ??。
