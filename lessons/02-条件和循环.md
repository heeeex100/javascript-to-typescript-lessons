## 边看边练

### 从一次加法开始，最后自己写统计器

每段讲解后就有一道小练习。先练明白这一个动作，再进入下一段；六段结束后，用它们完成最后的综合题。

#### 1 · 先加一次，不写循环

先不写循环。想象账面上本来 0 元，收到 3 元后变为 3 元，又收到 5 元后变为 8 元。total 就是账面总数。

```js
let total = 0;
console.log("开始", total);
total = total + 3;
console.log("加了 3 后", total);
total = total + 5;
console.log("再加 5 后", total);
```

这段程序可以直接点“运行这个例子”。这一次先只盯住 `total = total + 3`：先读右边旧的 total=0，算出 0+3=3，再把 3 存回左边的 total。`=` 在这里是保存新值。

小练习先让你只做第一次加法。

##### 就地小练习 02-01 · 先加一次，不写循环

total 初始为 0。只改第二行，让它把 3 加到已有总数上。

```js
let total = 0;
total = total;
console.log(total);
```

#### 2 · 接着再加一次

已有总数是 3，又来了 5。`total = 5` 是把旧总数直接换成 5；`total = total + 5` 才是在旧的 3 上加 5，得到 8。

| 这一步 | 旧的 total | 右边先计算 | 新的 total |
| --- | --- | --- | --- |
| 加 3 | 0 | 0 + 3 | 3 |
| 再加 5 | 3 | 3 + 5 | 8 |

所以代码中左右两个 total 的角色不同：右边先取旧值，左边再存新值。下一题故意把旧总数覆盖了，由你修好。

##### 就地小练习 02-02 · 接着再加一次

第一步已经加了 3。修改最后一次赋值，保留这 3，再加 5，最终得到 8。

```js
let total = 0;
total = total + 3;
total = 5;
```

#### 3 · 让相同动作重复三次

数组 `[2,3,5]` 是按顺序放好的三个数。for...of 可以读成“每次拿一个数，叫 number，再做花括号里面的动作”。

```js
let total = 0;
for (const number of [2, 3, 5]) {
  total = total + number;
  console.log(number, total);
}
```

输出是 2 2、3 5、5 10。每次加法都用到了上一次留下的总数。total=0 放在循环前，只在开始执行一次。

如果把 `let total = 0` 移进循环，每次又会从 0 开始，输出就只剩 2、3、5。先自己把这两个版本对比运行一次，再做小题。

##### 就地小练习 02-03 · 让相同动作重复三次

在循环内补上一次加法，让 total 最终等于 10。

```js
const numbers = [2, 3, 5];
let total = 0;
for (const number of numbers) {
  console.log("这次拿到", number);
}
console.log(total);
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 02-03 --prepare`，编辑 `practice/steps/02-03.js`，再运行 `npm run drill -- 02-03 --check`。

<details>
<summary>一点提示</summary>

每次循环的 number 都不同；在花括号里面用 total = total + number。

</details>

<details>
<summary>试过后再看解释</summary>

```js
const numbers = [2, 3, 5];
let total = 0;
for (const number of numbers) {
  total = total + number;
  console.log("这次拿到", number);
}
console.log(total);
```

循环帮你重复同一行加法，每次读取数组里的下一个数。

</details>

#### 4 · 刚好等于也要算

“至少 25 分钟”包括刚好 25。`30 > 25` 是 true，但 `25 > 25` 是 false；`25 >= 25` 才是 true。

```js
console.log(25 > 25);
console.log(25 >= 25);
```

两次分别输出 false、true。这两个值表示“不符合”和“符合”。后面的 if 就用这个答案决定是否执行里面的代码。下一题先只问“这个数是否达标”，不把循环也放进来。

#### 5 · 加法只在条件成立时执行

现在把前面两件事组合起来：循环让每个数字都来看一次，if 决定这一个数字要不要加入总数。

```js
let total = 0;
for (const number of [2, 3, 5]) {
  if (number >= 3) {
    total = total + number;
  }
}
console.log(total);
```

2 不符合条件，跳过加法；3 和 5 符合，总数为 8。循环没有因为跳过 2 就结束，仍然继续看后面的数。

大题还需要数次数：达标时 count=count+1，未达标时可以在 else 里让 skipped=skipped+1。else 表示前面条件不成立时走的另一条路。

##### 就地小练习 02-05 · 加法只在条件成立时执行

只累加大于或等于 3 的数：2 跳过，3 和 5 加入，总数为 8。

```js
const numbers = [2, 3, 5];
let total = 0;
for (const number of numbers) {
  total = total + number;
}
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 02-05 --prepare`，编辑 `practice/steps/02-05.js`，再运行 `npm run drill -- 02-05 --check`。

<details>
<summary>一点提示</summary>

循环决定每个数都来看一次；if 决定这个数要不要加。

</details>

<details>
<summary>试过后再看解释</summary>

```js
const numbers = [2, 3, 5];
let total = 0;
for (const number of numbers) {
  if (number >= 3) {
    total = total + number;
  }
}
```

不是停止循环，而是当前不满足条件的数不参与加法。

</details>

#### 6 · 换一组输入验证自己

最后再用新输入检验这套方法，不把答案写死。原来 [2,3,5] 的达标总数是 8，换成 [] 就应为 0，换成 [3,3] 就应为 6。

下面的小题已经提供函数外壳，这关只需把刚才的初始化、循环、条件放进去，最后返回 total；函数的完整用法在第 03 关继续学。

大题还要求平均时长：把达标总时长除以达标次数。`/` 是除法，例如 65/2 得到 32.5。没有达标记录时，次数是 0，这时不做除法，保留 average=0：

```js
const total = 65;
const count = 2;
let average = 0;
if (count > 0) average = total / count;
console.log(average);
```

`total += number` 只是 `total = total + number` 的简写。总数不断加入新值的做法常叫累加；名字可放后面记，先把数值变化说清楚。

##### 就地小练习 02-06 · 换一组输入验证自己

完成 sumAtLeast3，不写死结果。试普通列表、空列表、全不达标三种情况。

```js
function sumAtLeast3(numbers) {
  return 8;
}
```

网页中在这一段下面直接练习。本地运行 `npm run drill -- 02-06 --prepare`，编辑 `practice/steps/02-06.js`，再运行 `npm run drill -- 02-06 --check`。

<details>
<summary>一点提示</summary>

把前一题的 total 初始化、循环和 if 搬进函数，最后返回 total。

</details>

<details>
<summary>试过后再看解释</summary>

```js

```

</details>
