# 课程实验台体验审计 · 2026-10-25

本次按流程、视觉、动效与状态的顺序检查并修改了课程实验台，包含本次开始前已做的“下一段讲解定位”修复。没有安装第三方依赖，没有提交或推送。

## 工具与验证范围

使用本地文件与测试工具、浏览器自动化、截图和布局测量。浏览器中实际点击、输入、运行代码、下载与上传备份，并验证键盘操作。覆盖 19 关、82 段讲解及相应小练习、基础/进阶切换、综合题、指导弹窗和备份流程。

浏览器测试使用隔离浏览器中的学习记录，未修改学习者的 practice 文件。验证参考答案时从 answers 读取代码填入网页。题目起始代码中用于教学的错误仍然保留。

## 第一轮：流程体验

| 问题 | 修改与复验 |
| --- | --- |
| 切换讲解后保留旧滚动位置，容易以为直接跳到综合题 | 前进/后退定位到讲解导航与新标题，焦点移入新内容；最后一段显示明确的综合题过渡提示 |
| 从页底换关后看不到新课标题 | 上一关、下一关、课程和阶段切换定位到当前课程标题 |
| 恢复综合题起点会重新初始化整关、回到第一段 | 只重置当前综合题编辑器、输出与验收记录，保留讲解进度，焦点进入编辑器 |
| 品牌链接及讲解中的本地 Markdown 链接会离开实验台 | 普通点击在指导弹窗内阅读；保留组合键打开链接的浏览器行为 |
| 备份描述容易被理解为包含所有练习 | 在备份说明、导出反馈、导入提示中明确：仅含综合题草稿和验收记录，小练习草稿需另行保存 |
| 窄屏时当前课程可能在横向导航的屏幕外 | 选中课程后将其移到导航可视区域 |

## 第二轮：视觉与 UX

- 保留浅绿配色，限制长篇讲解为约 78 字符的阅读宽度。
- 综合题要求改为与编辑区相协调的独立卡片，验收按钮作为主要操作。
- 按钮至少 44 像素高；窄屏下讲解进度单独占一行，导航按钮并列。
- 调整窄屏内边距、编辑器标题换行和只读代码预览样式。
- 加入“跳到当前课程”键盘入口，统一输入、下拉框及可聚焦区域的焦点提示。
- 在 1440、768、390、320 像素宽度测量，均无页面水平溢出。切段后导航距视口顶部约 20 像素，讲解标题可见。
- 已检查桌面综合题界面、窄屏小练习错误状态的实际截图。

## 第三轮：动效与状态

| 状态/组件 | 结果 |
| --- | --- |
| 讲解切换 | 160ms 淡入与轻微位移；先完成定位，避免在旧位置继续点击 |
| 指导与导入弹窗 | 短暂入场过渡；指导加载有 aria-busy，标题取实际文档标题 |
| 运行中 | 综合题显示运行提示及旋转指示，小练习与讲解例子显示运行提示；运行期间禁止重复启动 |
| 成功/错误 | 小练习与综合题使用绿色/橙色结果背景和边框，同时保留文字反馈；例子错误有明确样式 |
| 编辑后 | 清除旧的成功/错误样式，提示重新运行或检查 |
| 停止/超时 | 主动停止和 3 秒超时均有反馈，恢复可运行状态 |
| 备份 | 实际下载后重新上传，验证取消、确认导入及无效 JSON 提示；现有测试覆盖冲突合并和覆盖逻辑 |
| 指导加载失败 | 模拟请求失败后显示恢复提示，结束加载状态；关闭后可重新打开 |
| 键盘与减少动态效果 | 弹窗 Tab 焦点留在弹窗内，Escape 可关闭；减少动态效果时动画数为 0、过渡为 0 秒 |
| 阶段切换与选择器 | 基础/进阶按钮使用 aria-pressed；课程用 aria-current。当前每段仅一题，原生小题选择器按设计隐藏，未增加虚假的多选入口 |

## 复验步骤

1. 启动 `npm run workshop`，打开终端显示的本机地址。
2. 选第 03 关，滚动到底点击继续；确认新讲解标题可见。回看上一步也应正确定位。
3. 到最后一段，确认提示下一步是综合大练习；进入后恢复起点，确认讲解进度仍为最后一段。
4. 输入错误代码、正确答案、等待代码和无限循环，分别检查错误、成功、停止与超时。
5. 打开完整指导，使用 Tab、Escape；导出并重新导入备份，再尝试无效 JSON。
6. 缩到窄屏，换关和阶段；开启系统减少动态效果，再检查切段和弹窗。

## 限制

浏览器自动化与视口模拟不等于真实手机、Safari 或屏幕阅读器测试；这些尚未验证。TypeScript 与模块题通过真实本地编译器/运行器验收，但未在另一台 Windows 电脑复验。用户长期学习时的主观节奏仍需实际使用反馈。小练习草稿的备份范围没有扩展，本次改进是清楚说明现有范围。

审计期间曾用错误的参考答案路径产生 404，改用实际 answers/practice 路径后相关网页综合题全部通过；这属于审计操作错误。指导请求失败测试中的网络错误为主动模拟。
