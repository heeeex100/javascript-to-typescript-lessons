# 题面修订 · 2026-10-31

上一轮把“问题说清楚”误解成“逐行写出怎么做”，并且只测试了空白浏览器，没有覆盖学习者保留的旧草稿。此版修正这两个问题。

## 题面

19 关移除“从哪里改起”的独立段落。基础综合题改为描述目标、结果和约束，算法与操作顺序留在折叠提示中。撤回前一轮对 15 道小题增加的逐行操作要求。网页及讲义同步。

第 01 关现在要求：

- input 是用户输入的文字分钟数，bonus 是额外增加的分钟数；保留 input 为文字。
- 给出 numeric（转换后的数字）、total（总分钟数）、valid（总分钟数是否为有限数字）三个结果。
- 无法转换时 numeric、total 为 NaN，valid 为 false。打印这三个结果。

例子：input="20"、bonus=5 → numeric=20、total=25、valid=true；input="abc" → numeric=NaN、total=NaN、valid=false。

这些名称是题目要求的结果，不再假定草稿已经包含这些行，也不再把替换语句直接写在题面上。

## 草稿

存在与起点不同的已保存代码时，编辑器显示“当前显示已保存草稿 · 查看本题起点”。展开可对照起点，恢复操作仍需确认。移除对恰好等于旧起点的草稿自动替换的行为，所有已有草稿都保留。

第 01 关验收增加 input 必须保留为文字的检查；缺少 numeric、total、valid 时给出检查提示，避免直接抛出未声明变量错误。

## 复验

隔离浏览器中使用截图同款代码（input=20，只有 total），确认草稿保持原样、提示与起点预览可见，验收说明 input 应保留为文字。取消恢复不会改变代码；确认恢复后，起点出现 numeric、total、valid。完成后普通输入与 abc 均验收通过，刷新保留修改。遍历 19 关，题目要求和例子均存在。
