# 进阶挑战：让已有知识解决完整问题

先从 **第 13 关**开始。每关先运行起始代码，复现问题；按需求完成一段可独立运行的业务逻辑，再用检查反馈迭代。无需先学前端框架，也不需要真实接口或账号。

| 关卡 | 你要完成的能力 | 难度与建议安排 |
| --- | --- | --- |
| [13 · 任务查询](13-task-query.md) | 关键词、状态、排序、分页与原数据保护 | ★★ · 45～60 分钟 |
| [14 · 撤销重做](14-undo-redo.md) | past / present / future、分支失效、实例隔离 | ★★ · 45～75 分钟 |
| [15 · 请求竞态](15-latest-request.md) | 后发先回、旧失败、相同关键词重复请求 | ★★★ · 60～90 分钟 |
| [16 · 并发任务池](16-concurrency-pool.md) | 限制启动数量、失败隔离、按输入顺序汇总 | ★★★ · 60～90 分钟 |
| [17 · 脏数据导入](17-validate-import.md) | unknown 校验、错误路径、全量错误收集 | ★★★ · 60～90 分钟 |
| [18 · 类型安全通知器](18-typed-events.md) | 事件名与载荷关系、取消订阅、派发快照 | ★★★★ · 75～120 分钟 |

时间只是参考，建议一天做一关或拆成两天。13、14 关完成后再进入异步；17、18 关需要前面 TS 基础。

## 立刻开始

```sh
npm run workshop
```

在实验台顶部选“进阶 13–18”，或打开 [第 13 关](http://127.0.0.1:8766/workshop/#13)。13～16 可直接在网页改代码；17～18 需要本地编辑和真实 TS 编译。

本地练习命令：

```sh
npm run lab -- 13
npm run lab -- 13 --check
```

Windows 中可将 npm 写成 npm.cmd。第一次缺少编译器时先运行 `npm.cmd ci --ignore-scripts`。

验收脚本不会替你补代码，也不会覆盖旧练习。`npm run verify:advanced` 用内置起始代码与参考答案检查教学材料，**不是检查你的作业**；自己的完成情况用 `npm run lab -- 关卡 --check`。

## 每关分三轮

1. **复现与最小修复**：让一个最小正常例子成立，保留日志观察过程。
2. **边界与失败**：处理空数据、无效参数、乱序、错误分支；根据合同决定行为。
3. **扩展与复盘**：自己增加一个需求，写下至少一个失败例子和通过例子；最后再看参考答案。

题目刻意不要求背复杂语法。第 18 关的类型负向验收会用 `@ts-expect-error`：预期不合法的调用必须报错，若你把公开类型改成 any，验收反而会失败。

## 做完之后，把功能接起来

可选综合任务：给原任务页面增加搜索与分页，用不可变数组保存任务历史，模拟异步搜索并确保旧响应不会覆盖新结果，再用导入校验器加载任务。先复用你已通过的函数，每接入一项就手动验证一遍。

组合时先明确：筛选变化是否回第一页？撤销是否只撤销数据，还是也撤销筛选条件？导入失败时是否保留原任务？这些是需要你自己写下的业务规则。

可按需查阅 [MDN Promise.allSettled](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise/allSettled) 和 [TypeScript 映射类型](https://www.typescriptlang.org/docs/handbook/2/mapped-types.html)。题目与验收是本地编写的练习；文档用于查语法。
