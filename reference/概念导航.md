# 概念导航：从读懂代码到自己修改

每关完整讲义和实验台都有“动手前先认识”，按下面顺序串起基础概念。每节包含定义、可复制的小例子、输出解释、改动实验和折叠自测答案。00–12 建立基础，13–18 补足进阶挑战的前置知识。

小实验独立于挑战，不会自动修改草稿或改变通关记录。用 npm run concept -- 关卡编号 直接运行原例；加 --prepare 创建独立实验文件，修改后加 --local 运行。TS 先 npm ci；07 的 HTML 准备后用浏览器打开。
