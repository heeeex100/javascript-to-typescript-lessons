# 学习路线：先看具体代码，再做一小步

19 关讲解已拆成五步：看一个例子 → 逐行追踪值 → 改一个地方 → 分开练 → 最后认识名称。实验台每次只展示一步，可前后翻看；完整讲义包含全部内容。

共有 60 道带运行检查的小练习。第 02 关有六道，从“加一次”逐渐到“带条件循环”；其余关各三道。先做小题，再做原有主挑战。用 npm run drill -- 02-01 --prepare 创建本地小题，修改后用 npm run drill -- 02-01 --check；网页 JS 小题可直接编辑。

原例仍可用 npm run concept -- 关卡编号 运行；加 --prepare 创建独立实验文件，加 --local 运行修改版本。TS 先 npm ci，07 的真实 DOM 在浏览器操作。
