# 学习路线：讲一段，就练一下，最后做综合题

每段讲解正下方都有对应小题，不再集中到最后。做完一小题后可以进入下一段；最后把本关知识组合成一个完整任务。第 02 关有六段，其余关各三段，共 60 道就地小练习和 19 个综合大练习。

JS 在网页里编辑、运行、检查；TS 小题用 npm run drill -- 08-01 --prepare 创建文件，修改后用 npm run drill -- 08-01 --check。综合题用 npm run lab -- 08 --check。基础综合题文件在 practice/finals；旧文件继续保留。
