# 学习路线：讲一段，就练一下，最后做综合题

每段讲解正下方都有对应小题，不再集中到最后。做完一小题后可以进入下一段；最后把本关知识组合成一个完整任务。各关按知识点安排段数，共 82 道就地小练习和 19 个综合大练习。

普通 JS 小题在网页里编辑、运行、检查；模块、断点与 TS 小题在本地完成。例如 npm run drill -- 05-04 --prepare 会创建两份模块文件，重复准备不覆盖修改；保存后用 npm run drill -- 05-04 --check。综合题用 npm run lab -- 05 --check。基础综合题文件在 practice/finals；旧文件继续保留。
