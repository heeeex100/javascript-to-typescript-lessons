### 数组、对象、回调与引用

**对象**把同一事物的属性放在一起，**数组**按顺序存放一组值。`task.title` 读取属性，`tasks[0]` 读取第一项，`tasks.length` 是数量。

- **回调函数**是作为参数交给另一个函数的函数。例如 `filter(task => !task.done)` 会对每项调用你的判断；由 filter 决定什么时候调用它。
- **数组方法**：filter 按条件保留元素，map 把每项转换成新值，find 返回首个匹配元素或 undefined，some 返回是否至少有一项匹配。filter/map 都返回新数组。
- **引用**：`const alias = tasks` 不会复制数组，两个名字指向同一个数组。`const` 只限制重新赋值，不阻止 push 或属性修改。
- **浅拷贝**：`[...tasks]` 展开后创建新数组，但内部对象仍被共享。要修改某个对象又保留原对象，可用 `{ ...task, done: true }` 创建新对象。这仍不会自动深拷贝嵌套对象。

<details>
<summary>读例子 → 改一个地方 → 检查理解</summary>

```js
const books = [{ title: "JS", read: false }];
const titles = books.filter(book => !book.read).map(book => book.title);
const copy = [...books];
copy[0].read = true;
console.log(titles[0], books[0].read);
console.log(copy === books, copy[0] === books[0]);
```

**逐步理解**：输出“JS true”和“false true”：数组容器复制了，内部的书对象仍是同一个。titles 中已经取出的字符串不会跟着对象属性变化。

**动手试一试**：把 copy 的构造改成 books.map(book => ({ ...book }))，重新预测 read 与两次 === 的结果。
