### 一张任务卡真的可能没填备注

先想两个输入：一张卡写了备注“重点”，另一张完全没填。函数都要返回能显示的文字。先处理“没填”，再处理“只填空格”。

#### 1 · 有时候确实没有备注

```ts
interface Card { title: string; note?: string }
const card: Card = { title: "复习", note: "   " };
const trimmed = card.note?.trim();
console.log(JSON.stringify(trimmed));
console.log(trimmed ?? "缺失");
console.log(trimmed || "空白或缺失");
```

原例可在终端运行：`npm run concept -- 09`。

`interface Card` 说明这种卡有哪些字段。title: string 要求标题是文字；note?: string 中的问号说“备注可以不提供”。

例子里 note 是三个空格。trim() 去掉两侧空格后，得到空字符串，也就是没有字符的 ""。第一条日志用 JSON.stringify 把引号显示出来，帮助你分清空字符串和没输出。

`card.note?.trim()` 中的 ?. 表示：没提供 note 时就停在这里，结果为 undefined；提供了才调用 trim。

然后比较两个默认值：trimmed ?? "缺失" 在空字符串时仍保留空字符串，所以会看到空行；trimmed || "空白或缺失" 则会替换空字符串，因此显示默认文字。


`interface Card { title: string; note?: string }` 中，花括号列出字段要求，冒号后是类型；分号分隔成员。`const card = { title: "复习" }` 中，花括号创建对象，冒号后是具体值，逗号分隔成员。它们相似，但不能把 string 当作标题内容，也不能拿声明好的 Card 当函数去创建卡片。

`const card: Card` 引用了这份类型要求，interface 本身不会在运行时生成对象。`note?` 表示对象可以缺少这个属性，并非必须写成空字符串。开启严格空值检查时，null 也不会自动等同于可省略的 string 属性；真想接收 null，要在类型里明确允许。

#### 2 · 有值时再去空格

将三个输入放在同一份完整例子里比较：

```ts
interface Card { title: string; note?: string }
const cards: Card[] = [
  { title: "A" },
  { title: "B", note: "  重点  " },
  { title: "C", note: "   " },
];
for (const card of cards) {
  console.log(card.title, JSON.stringify(card.note?.trim()));
}
```

三项对应 undefined、"重点"、""。这一步只去空格，暂时不补默认文字，和下面小题的要求一致。

试着删除 B 卡片的 note，再把 C 的 note 改为 "  新备注  "。结果应分别变成 undefined 和 "新备注"。先只观察 ?.trim()；下一段再处理“没有备注或只有空白，都显示无备注”的默认值。


同一行可能有三种问号：`note?: string` 是类型中的可选字段；`card.note?.trim()` 是运行时可选链；`trimmed ?? "缺失"` 是默认值规则。`?.` 在左边为 null 或 undefined 时停止这条访问链，不会把空文字当成缺失。已有 note 却存了数字时，它也不会把数字变成字符串来让 trim 成功。

trim() 返回去掉两侧空白的新字符串，不会自动改写 card.note。你可以打印 `JSON.stringify(card.note)` 和 `JSON.stringify(trimmed)`，前者仍有空格，后者没有。要存回去需要实际赋值，而且还要符合字段类型。

#### 3 · 空字符串也需要默认值

去空格之后，再处理空字符串与缺失值：

```ts
const notes: (string | undefined)[] = [undefined, "", "重点"];
for (const note of notes) {
  console.log(note || "无备注");
}
```

输出“无备注”“无备注”“重点”。将 || 换成 ?? 后，中间一项会保留空字符串，可以对比这两种规则。

? 标注的是**可选属性**；?. 是**可选链**，让缺失时停止访问。

?? 只给 null/undefined 补默认值；|| 还会给空字符串、0、false 等补默认值。先写清自己想保留哪些值，再选运算符。
