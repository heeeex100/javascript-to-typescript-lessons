### JSON、异常与模块边界

**JSON**是一种数据文本格式，便于保存和传输；它不是 JS 对象本身。JSON 的键和字符串使用双引号，不能写注释、undefined 或函数。

- **序列化 / 解析**：`JSON.stringify(value)` 把可表示的数据转成文本；`JSON.parse(text)` 把符合 JSON 语法的文本转回 JS 值。解析成功也可能得到 null、数字或对象，不一定是数组。
- **异常**：`throw` 表示当前操作无法正常继续；控制流会跳向匹配的 catch，try 里抛错之后的语句会被跳过。只在能处理的边界接住错误。
- **错误边界**：语法检查回答“这是不是合法 JSON”；结构检查回答“是不是我需要的数据”。`Array.isArray(value)` 只检查外层是数组，不检查每个任务的字段。
- **模块**：一个文件可通过 `export` 暴露功能，另一个文件用 `import` 引入。两者是源码语法；npm 是管理包和运行脚本的工具，Node.js 才执行脚本。本项目的 package.json 使用 type: module。

```js
const saved = JSON.stringify({ title: "复习" });
console.log(typeof saved, JSON.parse(saved).title);
try {
  JSON.parse("oops");
  console.log("这里不会执行");
} catch (error) {
  console.log(error instanceof SyntaxError);
}
console.log(Array.isArray(JSON.parse("null")));
```

**逐步理解**：输出“string 复习”“true”“false”。try/catch 没有把坏文本变成好数据，只让程序有机会走失败处理分支。
