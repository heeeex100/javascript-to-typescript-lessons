### Promise、async、await 与执行顺序

**异步操作**允许等待期间运行其他工作。Promise 表示一个操作未来的结果，它有 pending（等待）、fulfilled（成功）和 rejected（失败）三种状态；一旦完成，就不会再变成另一种完成状态。

- **async 函数**总返回 Promise。内部 return 的值会成为成功结果，未处理的 throw 会成为失败结果；调用得到的不是直接的数据。
- **await**取得成功结果，遇到拒绝会在等待处抛出；它暂停当前异步流程的后续执行，不阻塞整个 JS 运行环境。await 后的继续执行会异步发生，即使结果已就绪。
- **回调与计时器**：setTimeout 安排稍后调用回调，延迟不是精确执行时刻，也不会阻塞等候。`new Promise(resolve => ...)` 中的 resolve 用来交付成功结果。
- **顺序与并发**：先 await A 再发起 B 是顺序；先发起 A、B 再用 Promise.all 等待，可以并发推进。Promise.all 有一项失败就会拒绝，但不会自动取消其他操作。

```js
async function loadLabel() {
  console.log("进入函数");
  await Promise.resolve();
  return "已完成";
}
console.log("开始");
const request = loadLabel();
console.log("继续主流程");
console.log(await request);
```

**逐步理解**：顺序是“开始 → 进入函数 → 继续主流程 → 已完成”。函数调用会立即执行到第一次 await，再把控制权交回。这里的顶层 await 可在实验台和 Node 的 ES 模块中使用。

**动手试一试**：把 Promise.resolve() 改为 new Promise(resolve => setTimeout(resolve, 500))；然后改为 Promise.reject(new Error("失败"))，在调用处尝试 catch。
