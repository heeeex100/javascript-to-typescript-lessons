### 从结账计算到能保留状态的工具

想象结账：给程序“单价 7 元、买 3 件”，希望它交回 21。函数让你把计算写一次，之后换一笔订单继续用。

#### 1 · 先让调用方拿到结果

```js
function cost(price, count) {
  return price * count;
}
const payment = cost(7, 3);
console.log(payment);
```

原例可在终端运行：`npm run concept -- 03`。

第一到三行只是在说明 cost 怎么工作，还没有买任何东西。`price, count` 是两个接收位置，你可以先读作“单价、数量”。

执行到 `cost(7, 3)` 时，才真正开始算：这次 price 是 7，count 是 3。到函数里算 7×3，得到 21。

`return` 把 21 交回调用的位置，所以这一行等价于 `const payment = 21`。之后 console.log 才把 payment 的值显示出来。

对比 `console.log(price * count)`：它只负责当场显示 21，并没有把这个数交回来。如果函数没有 return，调用方拿到 undefined，表示这里没有返回你想要的值。屏幕看到数字，不等于下一段代码拿到了数字。


**return 后面为什么不能随意换行？**

下面两种写法看着只差一个换行，结果却不同：

```js
function sameLine() {
  return 7 * 3;
}
function nextLine() {
  return
    7 * 3;
}
console.log(sameLine());
console.log(nextLine());
```

输出分别是 21 和 undefined。JS 不允许 return 和它要返回的表达式之间出现换行，所以第二个函数会按 `return;` 理解：到这里就结束函数，没有交回计算结果。后面的 7 * 3 根本不会执行。

即使你在 7 * 3 后面加了分号，也补救不了前面的换行。要返回的表达式得从 return 同一行开始。如果表达式很长，可以把左括号放在 return 同一行，内容放到括号里分行写：

```js
function cost() {
  return (
    7 * 3
  );
}
console.log(cost());
```

这次返回 21。换行发生在括号里面，return 后面已经有左括号，不会变成一个空的 return。

**定义里的括号和调用里的括号**

`function cost(price, count) { ... }` 定义一个函数。function 是关键字，cost 是名字，括号里的 price、count 是接收位置，逗号将它们分开，花括号里是调用后要执行的代码。`cost(7, 3)` 才是调用，7 交给第一个位置，3 交给第二个位置，靠位置对应，不靠变量名猜。

调用参数通常从左到右计算，例如 `cost(5 + 2, 3)` 先得到 7，再进入函数。少传的参数若没有默认值，会得到 undefined；多传的参数在这个函数体里没有被读取，就不会参与计算。`cost()` 的空括号仍然会调用函数，只是没有提供参数；单独写 cost 则不调用。

普通函数声明结尾的 `}` 不要求像 const 声明一样再写分号。括号和花括号里的换行、缩进方便人阅读；决定嵌套关系的仍是实际符号。

#### 2 · 参数每次都可以换

先把调用改为 cost(5, 2)，应得到 10。再改为 cost(5, 0)，应得到 0。不要修改函数体，这样才能体验“同一段方法，换输入复用”。

再把 return 那一行改成 console.log(price * count)。观察会先打印 10，再打印 undefined。恢复 return，并尝试 `const doubled = cost(5, 2) * 2`。

最后才认识简写：`const double = value => value * 2` 可以先读成“接收 value，返回 value×2”。如果写成 `value => { ... }`，花括号内还要写 return 才能交回结果。

#### 3 · 再把两个函数连起来

函数定义里接收数据的名字叫**形参**，调用时传的具体数据叫**实参**。调用表达式拿回来的东西叫**返回值**。

函数内创建的变量通常只能在里面使用，想给外面用，就返回它。`count = 1` 这种默认参数表示没传 count 时使用 1；传 0 则应使用 0，后面会单独用小题比较“没传”和“传 0”。

#### 4 · 普通函数看懂后，再缩短写法

下面三种写法都接收一个数字，返回两倍：

```js
function doubleA(value) { return value * 2; }
const doubleB = value => value * 2;
const doubleC = value => { return value * 2; };
console.log(doubleA(4), doubleB(4), doubleC(4));
```

输出 8、8、8。箭头左边是接收位置，右边是要做的事。只有一个参数时可省略它的括号；两个参数可以写 `(price, count) => price * count`。

最常见的坑是写成 `value => { value * 2; }`：里面算了，却没交回结果，所以得到 undefined。花括号表示函数体时，要明确写 return。只有表达式的简写才会自动返回那个表达式的值。

先把普通函数改写成箭头函数，然后故意去掉 return，再恢复。两种函数在 this 上还有差别，当前先用显式参数完成计算，不把它们当作所有场合都能互换的写法。

**哪些地方能简写，哪些不能？**

```js
const noInput = () => 7;
const oneInput = value => value * 2;
const twoInputs = (a, b) => a + b;
const makeCard = title => ({ title: title });
console.log(noInput(), oneInput(4), twoInputs(2, 3), makeCard("JS").title);
```

输出 7、8、5、JS。没有参数时保留空括号；一个普通参数可以省略括号；两个参数要用括号包住并用逗号分隔。箭头 `=>` 连在一起，不是大于等于 `>=`。

`title => ({ title: title })` 中，外层小括号让花括号被当作一个对象表达式，直接返回对象。若写 `title => { title: title }`，这里被解析为函数体，不会自动返回那张卡。也可以写完整的 `title => { return { title: title }; }`。箭头函数赋给 const 的整条声明，结尾仍按声明写分号。

#### 5 · 把工具交给别人，等别人调用

函数也能存进变量、传给另一个函数：

```js
function double(value) { return value * 2; }
function apply(value, operation) { return operation(value); }
console.log(apply(4, double));
console.log(apply(4, value => value + 3));
```

第一笔调用的过程：把数字 4 和函数 double 交给 apply；apply 内的 value 是 4，operation 是那个函数；执行 operation(value) 才调用 double(4)，返回 8。第二笔换一个工具，返回 7。

`double` 是工具本身；`double(4)` 是立刻使用工具后得到的数字。可以比较 `typeof double` 与 `typeof double(4)`，分别是 function、number。

因此 `apply(4, double(4))` 会把数字 8 交给 operation，随后不能再把它当函数调用。先猜它在哪一行失败，再实际运行。交给别人、由别人调用的函数，叫**回调函数**。下一关 filter 和 map 会重复使用这个动作。

#### 6 · 同名变量要看它在哪里声明

```js
const price = 12;
function showPrice() {
  const price = 5;
  console.log("里面", price);
}
showPrice();
console.log("外面", price);
```

输出“里面 5”“外面 12”。函数里面新声明了自己的 price，不是把外面的 12 改成 5。内部读取名字时先找自己所在范围，再向外找。

let/const 还受花括号限制。在 `if (true) { const note = "仅内部"; }` 后面读取 note，会得到 ReferenceError，因为这个名字不能在块外使用。可以用另一个小文件故意试一次，读报错中的变量名。

注意“新声明”与“赋值”不同：如果外面是 `let price = 12`，里面只写 `price = 5`，没有创建自己的变量，就会修改找到的外部变量。下一题对比这两个版本。

变量可以在哪些地方被读取或修改，这个范围叫**作用域**。先学清 let/const；阅读旧代码遇到 var 时，要记得它没有同样的块作用域规则。

#### 7 · 没传参数，才用默认值

```js
function cost(price, count = 1) { return price * count; }
console.log(cost(7));
console.log(cost(7, 0));
console.log(cost(7, undefined));
```

输出 7、0、7。省略第二个参数或传 undefined 时，count 使用默认值 1；传 0 表示明确买 0 件，应该保留。

不要在函数里面用 `count = count || 1` 代替它：上一关已经看到 || 会把 0 也换掉。传 null 不会触发默认参数，具体是否接受 null 需要另做输入校验；本题只练有效数字与未提供参数。

默认参数并不是每次调用都追加一份奖励，而是在缺少那个输入时选择起始值。

#### 8 · 函数结束后，还能记住那个数吗

```js
function createCounter() {
  let count = 0;
  return () => {
    count = count + 1;
    return count;
  };
}
const next = createCounter();
console.log(next());
console.log(next());
```

输出 1、2。执行 createCounter() 时先创建 count=0，然后交回一个函数，保存为 next。这时还没有加 1。第一次 next() 才加到 1，第二次使用同一份 count，再加到 2。

把 count=0 移进返回的箭头函数试试：每次 next() 都重新创建并清零，就只能得到 1、1。把这两个版本的执行过程画成“创建一次”和“每次调用”两栏。

返回的函数与创建时所在范围的变量保持关联，这叫**闭包**。先体验“同一个函数能继续使用上次的数”，再记这个名字。它不是把数字永远复制成创建时的 0。

`return () => { ... }` 返回的是一个还没有执行的函数，不是此刻就把里面的每行再执行一次。可以打印 `typeof next`，会得到 function；打印 `next()`，才会得到这次计数的数字。把原来的 `const next = createCounter()` 改成 `const next = createCounter`，next 就成了工厂本身，next() 会创建另一个函数，当然不是得到 1。这是调用括号位置不同导致的实际行为变化。

#### 9 · 两次创建，要有两份独立记忆

在上一段的 createCounter 中加入 start 参数，用它初始化 count，再创建两个计数器：

```js
function createCounter(start) {
  let count = start;
  return () => { count += 1; return count; };
}
const a = createCounter(0);
const b = createCounter(10);
console.log(a(), b(), a(), b());
```

输出 1、11、2、12。调用 createCounter 两次，各自创建一份 count。a 只改变自己的数，b 不受影响。如果把 count 提到所有函数外面，它们反而会共用状态。

到这里你已经分别练过：返回结果、接收不同输入、传递函数、控制变量范围、保留独立状态。下一段先学一次交回两个值，最后的综合题再把这些动作组合成“可选择计算规则、会记录订单数的结账工具”。先自己列出它的输入、返回值和需要记住的变量，再看提示。

#### 10 · 一次交回金额和次数

综合题既要告诉调用方“多少钱”，又要告诉它“第几单”。可以把两个值放到一份带栏名的单据里：

```js
function receipt(total, orders) {
  return { total: total, orders: orders };
}
const bill = receipt(24, 1);
console.log(bill.total);
console.log(bill.orders);
```

输出 24、1。return 交回的仍然是一个值，这个值是一份有两栏的数据。冒号左侧的 total 是栏名，右侧 total 读取本次传入的参数。逗号把两栏分开。bill 保存整份结果，bill.total 用点号读其中一栏。

这种带字段的数据叫对象，下一关会专门练它。这里先练“返回两栏，分别读取”就够了。两个名字相同时，`{ total: total, orders: orders }` 也可简写为 `{ total, orders }`；先用长写法看清对应关系。

最后组合时，计算规则也可以有默认值：`adjust = amount => amount` 表示没提供规则时使用“接收多少就返回多少”的函数。创建工具时保存这个函数，真正结账时才调用它。不要因为看到箭头就立即执行。
