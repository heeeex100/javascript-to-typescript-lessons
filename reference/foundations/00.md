### 程序、运行环境与一行代码

**程序**是一组让计算机执行的指令。源码是你写下的文本，**运行**才会让指令产生结果。当前练习大体按从上到下的顺序执行；第 06 关再观察异步带来的变化。

- **JavaScript（JS）**是语言；浏览器和 Node.js 都能执行它，也各自提供不同的工具。
- **运行环境**提供语言之外的能力：浏览器能操作页面 DOM，Node.js 能通过模块读写文件。Node.js 可以用来写服务器，也能只运行一个脚本；可类比 Java 的运行环境，但 API 和执行机制不同。
- **变量名**是访问一个值的名字；`const` 建立不能重新赋值的绑定。`const topic = "数组";` 中，`topic` 是名字，`"数组"` 是字符串值，`=` 把右侧结果绑定到左侧。
- **表达式**会求出一个值，如 `10 + 5`；**语句**完成一步操作，如 `const minutes = 10 + 5;`。`console.log(...)` 是函数调用，用来显示值；`//` 后面是给人读的注释。
- **模板字符串**用反引号包围，`${...}` 会计算并插入表达式。字符串里的字和变量名不是一回事。

<summary>读例子 → 改一个地方 → 检查理解</summary>

```js
const topic = "数组";
const minutes = 10 + 5;
console.log(`${topic}：${minutes} 分钟`);
console.log("topic");
```

**逐步理解**：第一行给名字绑定文本；第二行先计算再绑定。两次输出依次是“数组：15 分钟”和“topic”。普通引号中的 topic 不会查找变量。

**动手试一试**：把第二行的 5 改成 10，预测哪条输出会变化。只改引号中的 topic，又会怎样？
