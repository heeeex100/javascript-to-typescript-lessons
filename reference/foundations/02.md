### 条件、布尔值与循环状态

**控制流程**决定下一步执行哪行。`if` 根据条件选择执行，`for...of` 则对可迭代的数据（这里是数组）逐项执行同一段代码。

- **布尔值与比较**：`>=` 包含边界，`>` 不包含。`===` 比较是否相等；不要误写成赋值的 `=`。`&&`、`||`、`!` 分别常用于“并且”“或者”“取反”。
- **真值转换**：if 也接受非布尔值；0、空字符串、null、undefined、NaN 会按假处理，但空数组 `[]` 和空对象 `{}` 按真处理。表达业务规则时优先写明确比较。
- **循环变量**：`for (const score of scores)` 每轮把当前元素绑定到 score；它不是下标。数组下标从 0 开始。
- **累加器与作用域**：循环外的 total 保留跨轮状态；`+=` 等同于先加再赋值。花括号形成块，块内声明的 let/const 只能在该块及内层使用。
- **边界输入**：刚好等于阈值、空数组、全部不达标，分别能发现不同遗漏。

<summary>读例子 → 改一个地方 → 检查理解</summary>

```js
const scores = [2, 3, 5];
let total = 0;
for (const score of scores) {
  if (score >= 3) total += score;
  console.log(score, total);
}
console.log("最终", total);
```

**逐步理解**：每轮输出“2 0”“3 3”“5 8”，最后输出“最终 8”。不满足条件时没有累加，但循环仍会继续。

**动手试一试**：把 >= 改为 >，再把数组改成 []。运行前先写出两种情况的最终值。
