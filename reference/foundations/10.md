### unknown、联合类型与收窄

**联合类型**用 `|` 表示“可能是这些类型之一”。使用之前，要有证据确认当前是哪一种。**收窄**就是编译器根据条件把可能范围缩小。

- **unknown**允许接收任何值，但在检查之前不能随意读属性、调用方法。any 则绕过很多检查，因此外部数据优先以 unknown 进入。
- **运行时证据**包括 typeof、与 null 比较、Array.isArray、属性判断等。`typeof input === "string"` 分支里才能安全把 input 当字符串使用。
- **可辨识联合**给每种情况一个不同的字面量标签，例如 ok: true 与 ok: false；检查标签后，编译器能关联到对应字段。
- **字面量类型**true 只允许 true，区别于可为 true/false 的 boolean；这使标签能可靠地区分成功与失败。
- **失败是数据**：返回 `{ ok: false, error: ... }` 可让调用方明确处理预期失败；它和 throw 导致控制流跳转是不同的表达方式。

<details>
<summary>读例子 → 改一个地方 → 检查理解</summary>

```ts
type ReadResult = { ok: true; value: number } | { ok: false; error: string };
function readCount(input: unknown): ReadResult {
  if (typeof input !== "number" || !Number.isFinite(input)) {
    return { ok: false, error: "需要有限数字" };
  }
  return { ok: true, value: input };
}
const result = readCount("3");
if (result.ok) console.log(result.value);
else console.log(result.error);
```

**逐步理解**：字符串 "3" 不是数字，输出“需要有限数字”。result.ok 分支内可读取 value；失败分支可读取 error。标签使两组字段保持关联。
