# 02 · 条件和循环：让程序选择和重复

目标：根据任务状态做判断，用循环统计数据。

运行：`node examples/js/02-control.js`。

## 1. 条件是会求值的表达式

```js
const minutes = 30;
if (minutes >= 25) {
  console.log("完成一个学习时段");
} else {
  console.log("继续学习");
}
```

先计算 `minutes >= 25`，结果为 true 时执行第一块，否则执行第二块。花括号包围一个代码块。

`&&` 表示同时满足，`||` 表示至少一项满足，`!` 取反。它们会短路：左边已决定结果时，右边不再求值。`&&` 和 `||` 返回某个操作数的值，不保证返回 boolean。

## 2. “有值”和“是真”不是同一个问题

`false`、`0`、`""`、`null`、`undefined`、`NaN` 等会在条件中被当作假；空数组 `[]` 和空对象 `{}` 都会被当作真。

```js
const count = 0;
console.log(count || 10); // 10：把 0 也当成缺省值
console.log(count ?? 10); // 0：仅 null / undefined 时使用右侧
```

如果合法值可能是 0 或空字符串，默认值常常应该用 `??`。是否该排除空字符串，需要由业务规则决定。

## 3. 遍历一组数据

```js
const sessions = [20, 30, 15];
let total = 0;
for (const minutes of sessions) {
  total = total + minutes;
}
console.log(total); // 65
```

数组是按顺序保存多个值的容器。`for...of` 每次取出一个值，存进本轮的 `minutes`。`total` 在循环外声明，才能保存累计结果。`const` 用于每轮新建的绑定，不妨碍下一轮换一个值。

需要索引时也可以写 `for (let i = 0; i < sessions.length; i++)`，其中 `i++` 表示增加 1。数组索引从 0 开始，最大有效索引是 length - 1。初学遍历值优先用 for...of，不要把 for...in 当成它的替代。

## 练习

在 `scratch.js` 中遍历 `[10, 25, 40, 15]`：只累计不小于 25 的数字，同时统计它们的个数。预期总和 65，个数 2。再把数组改为 `[]`，预期两个结果都是 0。

思考：把 `let total = 0` 放进循环内部为什么会出错？把 `>= 25` 改成 `> 25` 后结果是什么？

## 验收

能独立写出“遍历 → 判断 → 累计”，并解释 `0 || 10` 与 `0 ?? 10` 的区别。
