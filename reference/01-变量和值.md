# 01 · 变量和值：先知道你拿到的是什么

目标：区分数字和字符串，理解 const / let，主动转换输入。

运行：`node examples/js/01-values.js`。

## 1. 变量保存值

```js
const name = "小杨";
let minutes = 20;
minutes = minutes + 10;
console.log(`${name} 学习了 ${minutes} 分钟`);
```

`const` 声明后不能重新赋值；`let` 允许重新赋值。先默认用 `const`，确实要更换绑定的值时用 `let`。本教程不用 `var`，避免一开始引入它不同的作用域规则。

反引号形成模板字符串，`${...}` 把表达式的值嵌进去。普通双引号不会替换 `${...}`。

注意：`const user = { name: "小杨" }` 后仍能写 `user.name = "小李"`。不可重新赋值的是 `user` 绑定；对象内部并没有因此冻结。

## 2. 常用值的类型

| 值 | `typeof` 结果 | 用途 |
| --- | --- | --- |
| `18`、`3.5` | `"number"` | 计算 |
| `"18"` | `"string"` | 文本、表单输入 |
| `true` | `"boolean"` | 条件 |
| `undefined` | `"undefined"` | 未提供的值、找不到的属性 |
| `null` | `"object"` | 主动表示空；typeof 的历史特殊情况 |
| `{ title: "学习" }`、`[1, 2]` | `"object"` | 组织数据 |

JS 还有 bigint、symbol 等类型，当前先不用。`typeof null` 不适合用来证明 null 是普通对象；数组判断用 `Array.isArray(value)`。

## 3. 转换决定计算结果

```js
const input = "20";
console.log(input + 5);         // "205"
console.log(Number(input) + 5); // 25
console.log("20" === 20);       // false
```

`+` 遇到字符串可能进行拼接。`Number(...)` 显式把输入转成数字；转换失败会得到 `NaN`。`Number.isFinite(value)` 同时排除 NaN 和正负无穷。

比较通常用 `===` 和 `!==`，避免 `==` 的隐式类型转换。`=` 是赋值，不是比较。

`Number("")` 和 `Number("   ")` 都是 0，所以“是数字”不等于“用户填写了数字”。实际校验要先检查空字符串。
