# 03 · 函数和作用域：把计算变成可复用的动作

目标：分清参数、返回值和打印，理解函数可以作为值传递。

运行：`node examples/js/03-functions.js`。

## 1. 定义不等于执行

```js
function totalMinutes(minutes, days = 1) {
  return minutes * days;
}
const result = totalMinutes(30, 5);
console.log(result); // 150
```

定义函数时描述规则；调用 `totalMinutes(30, 5)` 时才执行函数体。`minutes`、`days` 是形参，30、5 是此次调用提供的实参。没有提供 days 或传入 undefined 时使用默认值 1；传入 null 不会触发默认值。

`return` 把结果交还调用方，并结束这次函数调用。`console.log` 只负责显示信息。只打印却不 return 的函数，调用结果通常是 undefined。

## 2. 箭头函数也是函数

```js
const double = value => value * 2;
const doubleAgain = value => {
  return value * 2;
};
```

只有表达式的箭头函数可以省略 return；写了花括号形成函数体，就需要显式返回结果。返回对象字面量时可写 `value => ({ value })`，括号避免把对象误认成函数体。

函数还可以作为另一个函数的参数：

```js
function apply(value, operation) {
  return operation(value);
}
console.log(apply(4, double)); // 8
```

这里传入 `double` 本身，随后由 apply 调用；`double(4)` 则是立即调用并把结果传过去。数组方法和事件监听都会用到这个区别。

## 3. 作用域和闭包

```js
function makeCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}
const next = makeCounter();
console.log(next(), next()); // 1 2
```

外部不能直接访问函数内部的 count，但返回的函数仍能访问创建它时所在作用域的变量。这种关联叫闭包。重新调用 makeCounter 会创建另一个独立的 count。

补充：普通函数的 `this` 通常取决于如何调用；箭头函数使用外层的 this。现在优先写显式参数的函数，后续学对象方法时再深入，不要假设箭头函数与普通函数在所有场合完全等价。

## 练习
