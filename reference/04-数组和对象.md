# 04 · 数组和对象：把现实里的数据组织起来

目标：用对象表示一个任务，用数组表示任务列表，筛选并更新数据。

运行：`node examples/js/04-collections.js`。

## 1. 对象记录一个事物

```js
const task = { id: 1, title: "学习 JS", done: false };
console.log(task.title);
const { title, done } = task;
```

对象由属性名和值组成，点号访问已知名称的属性。解构把属性取出来，保存为同名变量。动态名称用方括号，例如 `task["title"]`。

数组可以存放多个对象：`const tasks = [task, { id: 2, title: "练习", done: true }]`。数组和对象都可嵌套。

## 2. 四个常用方法

| 方法 | 输入回调表达什么 | 返回什么 |
| --- | --- | --- |
| `filter` | 是否保留这一项 | 新数组 |
| `map` | 这一项转换成什么 | 新数组 |
| `find` | 这一项是否符合要求 | 第一项或 undefined |
| `reduce` | 如何更新累计结果 | 最终累计值 |

```js
const pendingTitles = tasks
  .filter(task => !task.done)
  .map(task => task.title);
```

从左到右：先留下未完成的任务对象，再把每个对象变成标题字符串。filter 的回调回答“保不保留”，map 的回调回答“变成什么”。如果只是要逐项打印，可以用 for...of，不必制造无用的新数组。

## 3. 更新与共享引用

```js
const alias = task;
alias.done = true; // task 也变了：两者指向同一个对象
const copy = { ...task, done: false }; // 新建对象，覆盖 done
```

展开语法 `...` 把已有属性复制到新对象，后面的同名属性覆盖前面的。展开只做浅拷贝：嵌套对象仍可能共享。

```js
const a = { meta: { minutes: 20 } };
const b = { ...a };
b.meta.minutes = 30;
console.log(a.meta.minutes); // 30
```

`map` 虽然返回新数组，但如果回调直接修改原对象，原数据也会改变。需要避免修改输入时，应返回 `{ ...task, done: true }` 这样的新对象。

## 4. 找不到是正常分支

`tasks.find(task => task.id === 999)` 返回 undefined。使用 `found?.title ?? "未找到"` 可以安全读取并提供默认值；`?.` 在左侧为 null 或 undefined 时停止访问，不能代替完整的输入校验。

## 练习

在 `exercises/js.js` 完成 `pendingTitles(tasks)` 和 `completeTask(tasks, id)`。后者返回新数组，将匹配项标为完成，不修改原对象；找不到 id 时返回内容不变的新数组。

## 验收

能解释 map 与 filter 的不同；能证明 completeTask 调用前后的原数组保持不变；知道浅拷贝不等于深拷贝。
