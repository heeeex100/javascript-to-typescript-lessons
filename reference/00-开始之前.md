# 00 · 先弄清代码在哪里运行

目标：运行一个 JS 文件，区分语言、运行环境和类型检查工具。

## 1. 四个名字，四个职责

| 名字 | 负责什么 | 类比或例子 |
| --- | --- | --- |
| JavaScript（JS） | 定义程序行为 | 变量、函数、循环 |
| 浏览器 | 执行 JS，并提供网页相关接口 | `document` 用于操作网页 |
| Node.js | 执行 JS，并提供文件等环境接口 | 在终端运行 `.js` 文件 |
| TypeScript（TS） | 在 JS 基础上增加类型语法和静态检查 | 发现把字符串传给数字参数等错误 |

JS 和 Java 是不同语言。JS 不要求把每个函数放进类里，也不需要先创建 `main` 方法。

本教程采用明确的 TS 运行过程：

```text
你编写 .ts → tsc 检查并生成 .js → Node 执行 .js
```

类型检查发生在运行之前。`number`、`interface` 等类型信息通常不会保留到生成的 JS 里。类型正确也不代表业务规则一定正确，例如“负数价格”依然属于 `number`。

## 2. 打开终端

可以用 macOS 终端或编辑器中的终端。下面的代码块是终端命令，不要粘贴到 `.js` 文件中。

```sh
cd javascript-to-typescript-lessons
node --version
npm --version
node examples/js/01-values.js
```

`cd` 改变终端所在目录；`node` 后面的路径告诉 Node 要运行哪个文件。终端显示的 `console.log` 内容就是程序输出。

如果提示 `node: command not found`，说明该终端找不到 Node。当前制作环境已装 Node，无需重复安装。若迁移到别的电脑，可从 [Node 官方下载页](https://nodejs.org/en/download) 安装受支持的 LTS 版本后重新打开终端。

## 3. 自己写第一段

在项目根目录新建 `scratch.js`，输入：

```js
const topic = "JavaScript";
console.log("今天开始学习", topic);
```

终端执行 `node scratch.js`，预期输出：`今天开始学习 JavaScript`。

`const` 声明绑定，`topic` 是名称，`=` 右侧是值；分号结束语句。字符串用引号包围。`console.log(...)` 调用函数把信息打印出来。`//` 后面是单行注释，不参与执行。

## 4. 学会看报错

把第二行里的 `topic` 改成 `topics`，再运行。你会得到 `ReferenceError`，因为这个名字没有声明。找到错误附近的文件名和行号，修正拼写。

常见错误：`SyntaxError` 多半是语法有问题；`ReferenceError` 表示名字访问有问题；`TypeError` 常见于对某个值执行了不支持的操作。具体原因要看错误信息，不能只看类别。

先读**第一条相关错误**，定位文件和行，再看周边代码；不要同时修改十个地方。
