## 参考了哪些讲解

- [MDN：语法与类型](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide/Grammar_and_types)：变量、初始化、大小写、注释与字面量。
- [现代 JavaScript 教程：代码结构](https://javascript.info/structure)：把有分号、无分号和改变解析结果的例子放在一起；借鉴对照讲法，示例按本课程重写。
- [现代 JavaScript 教程：函数](https://javascript.info/function-basics)：参数、默认值、返回值与省略写法的对照。
- [MDN：if...else](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Statements/if...else)、[箭头函数](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Functions/Arrow_functions)、[展开语法](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/Spread_syntax)、[可选链](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/Optional_chaining)：核对省略规则与常见歧义。
- [TypeScript：日常类型](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html)、[函数](https://www.typescriptlang.org/docs/handbook/2/functions.html)、[泛型](https://www.typescriptlang.org/docs/handbook/2/generics.html)、[收窄](https://www.typescriptlang.org/docs/handbook/2/narrowing.html)、[映射类型](https://www.typescriptlang.org/docs/handbook/2/mapped-types.html)：核对类型位置的符号与运行时表达式之间的区别。
